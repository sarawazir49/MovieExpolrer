## ✨ Features

- 🔍 **Search Movies** - Search by title instantly
- 🎭 **Filter by Genre** - Action, Comedy, Drama, Horror & more
- ⭐ **Sort Movies** - Most Popular, Top Rated, Newest, Oldest
- 📄 **Movie Details** - Overview, rating, release date, poster
- ❤️ **Favorites** - Save your favorite movies (Login required)
- 📱 **Responsive Design** - Works on mobile, tablet & desktop
- ⚡ **Fast** - Built with Vite for lightning fast loading

## 🛠️ Tech Stack

**Frontend:**
- React + Vite
- JavaScript / CSS
- Deployed on Netlify

**Backend:**
- Node.js + Express
- MongoDB
- JWT Authentication
